# AGENTS.md — public contribution guidance

This repository is a public reference and conformance surface for Veritas receipt and evidence contracts.

Use only the public source, contracts, tests, documentation, and repository rules when contributing or assisting with this repository.

## Public boundary

- Do not publish or infer private portfolio topology, layer numbering, private repository relationships, internal orchestration, research hypotheses, roadmaps, work claims, or branch ownership metadata.
- Keep public documentation focused on externally observable receipt, evidence, integrity, and conformance behavior.
- Public examples must not require private implementation knowledge.
- Contract changes require review, versioning where applicable, and public conformance evidence.

See `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, and the public test suite for repository-specific requirements.
